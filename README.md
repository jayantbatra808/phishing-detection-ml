# Phishing Website Detection using Machine Learning

A capstone project that detects phishing websites using a trained ML model,
served via an API and a browser extension.

## Status
🚧 Work in progress — Step 1 (dataset exploration) complete.

## Project structure
- `notebooks/` — exploratory & training notebooks
- `src/` — reusable Python modules
- `api/` — backend API serving the trained model
- `extension/` — browser extension frontend
